# Eventos Comunitarios 📅

Aplicación Android desarrollada en Kotlin para la gestión de eventos comunitarios.  
Este proyecto permite a los usuarios registrarse, iniciar sesión y visualizar eventos comunitarios utilizando Firebase como backend.

# 🚀 Características

- Registro de usuarios
- Inicio de sesión
- Integración con Firebase Authentication
- Gestión de eventos comunitarios
- Interfaz moderna en Android Studio
- Navegación entre pantallas
- Validaciones de formularios
- Diseño basado en Material Design

# ⚙️ Configuración del proyecto

## 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

---

## 2. Abrir el proyecto

Abrir el proyecto en Android Studio.

---

## 3. Configurar Firebase

1. Crear un proyecto en Firebase.
2. Registrar la aplicación Android.
3. Descargar el archivo `google-services.json`.
4. Colocar el archivo dentro de:

```txt
/app
```

---

## 4. Sincronizar Gradle

Esperar a que Android Studio sincronice las dependencias automáticamente.

---

## 5. Ejecutar la aplicación

Conectar un dispositivo Android o iniciar un emulador y ejecutar el proyecto.
